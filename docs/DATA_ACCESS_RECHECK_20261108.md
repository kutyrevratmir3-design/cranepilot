# Independent-data access recheck, 8 November 2026

No new raw recordings were downloaded or ingested in this stage.

- [Mendeley version 2](https://data.mendeley.com/datasets/x69hyyv3zw/2), dated
  16 May 2025, still describes 33 scenarios, 99 seconds each at 100 Hz.
  This is the existing experimental collection; it is not a fresh holdout.
  [Version 1](https://data.mendeley.com/datasets/x69hyyv3zw/1) is an earlier
  release of the same collection and does not establish independent trials.
- [Talapiden/Alhassan et al., JVC 2026](https://journals.sagepub.com/doi/abs/10.1177/10775463251411778)
  still states that study data are available on request to the corresponding
  author. No accessible new numerical supplement was verified.
- [Shehu/Alhassan/Talapiden et al., ISA 2026](https://www.sciencedirect.com/science/article/pii/S0019057826001990)
  remains an earlier identified lead. The publisher endpoint returned 403
  again. Neither accessible raw data nor an exact platform match was verified.
  A university abstract is not evidence of a downloadable raw dataset.

The targeted repeat search did not locate suitable new public trials. This
does not prove that none exist. The previously prepared author request and
intake protocol remain the route to independent confirmation. No message was
sent to any author. The dated-forecast development and replay use old records
and synthetic lag/noise only; the independent objective remains unmet.
