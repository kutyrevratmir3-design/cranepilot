В 59 из 90 прежних fine-tune запусков validation оставила исходные веса.

не использует эту модель. Ссылки и пределы переноса теории приведены в

## Зафиксированные данные и сравнения

Сохраняются все три train/validation/evaluation/load split из temporal provenance,

Headline — среднее MAE в градусах по 7 горизонтам (.1,.2,.35,.5,.75,1,1.5 с),
затем по целым extrapolation-сценариям каждого fold. Interpolation отдельно.
Окна не считаются независимыми статистическими повторениями.

Контроли: incumbent, soft_symmetry, physical, previous_local. Последнее —
зафиксированный победитель предыдущего этапа по validation: primary phase_space,

воспроизводятся непосредственно из сохранённых весов и сверяются с NPZ.

## Восемь моделей, 72 fits

Все добавочные модели используют замороженную soft-базу того же fold/seed.
Base weights сохраняются в state_dict и проверяются побитно; обучение и
валидация не могут обновить base. Нулевой выход новой части точно воспроизводит
soft при инициализации. Seeds 0,1,2, три fold.

1. `adapter_force8`: новый tanh MLP ширины 8 с нулевым последним слоем;
   ограниченная поправка проходит через затухающий осциллятор с omega(L).
2. `adapter_force16`: та же конструкция, ширина 16.
3. `adapter_direct8`: тот же малый head, ограниченная прямая поправка к углу
   вместо динамического фильтра. Это ablation с другим физическим смыслом
   и масштабом ограничения; не чистое сравнение только числа операций.
4. `adapter_force8_phase`: первый вариант с дополнительной phase-space потерей.
5. `latent_standalone6`: самостоятельная глобальная латентная модель размерности 6.
6. `latent_standalone12`: такая же модель размерности 12.
7. `latent_residual6`: латентная динамика как новый остаток поверх soft, выход нулевой.
8. `latent_residual6_phase`: предыдущая модель с phase-space потерей.

Adapter: 32 признака замороженного encoder, предыдущее базовое q и оценка p,
текущие известные u и acceleration, omega/5, номер горизонта. Soft symmetry .5
сохраняется для новой части. Force bound .05 rad, direct bound .02 rad,
затухание фильтра zeta=.05, нулевые начальные residual q,p. Это не онлайн
переидентификация существующего innovation-блока.

Latent: G=J0+.1(R-R^T)-diag(softplus(d)+.001), h=omega*.05,
A=(I-hG/2)^(-1)(I+hG/2), согласованный Cayley input mapping.
G+G^T отрицательно определена, поэтому автономный латентный переход сжимает
евклидову норму при положительном h. Начальное состояние зависит только от
истории; известная будущая команда и замороженный actor acceleration — входы.
Learned input/output maps не делают модель точной физикой. Гарантия относится
только к внутренней автономной системе, не к крану, frozen base или closed loop.

## Обучение и выбор

AdamW lr=.001, weight decay=.0001, batch 256, gradient clip 2; максимум 100 эпох,
patience 20, одинаковая перестановка TRAIN по seed. Основная потеря — mean
SmoothL1((forecast-target)/.1, beta=.1) на всех 30 шагах. Adapter дополнительно
штрафует квадрат нового ограниченного head с коэффициентом .01; standalone
и latent residual этого штрафа не имеют. Старые base regularizers постоянны
и не включаются в оптимизацию. Сравнение — разных семейств, не только оптимизаторов.

Phase варианты добавляют .25 SmoothL1(diff(error)/(omega*.05*.1), beta=.1)
и .25 SmoothL1(last_error/.1,beta=.1). Это surrogate временных приращений,
а не измеренная скорость, контрольная стоимость или гарантия управления.

Per-seed checkpoint минимизирует .5*(validation_all/initial_all +
validation_active/initial_active). Initial epoch -1 всегда допустим; его выбор
для residual означает отсутствие обученного улучшения. У standalone initial
свой; поэтому его fallback не равен soft. Сохраняются эпохи, шаги, время,
параметры, seed и выбранная эпоха. Checkpoint загружается повторно до ансамбля.

Ансамбль усредняет 3 seed. Допустимость по validation относительно previous_local:
all <= 1.00, active <= 1.01, quiet <= 1.01. Из допустимых выбирается minimum all.
Common выбирается тем же правилом на всех трёх fold и минимумом среднего
нормированного all. Контроль previous_local всегда обеспечивает fallback.
Selection и SHA всех checkpoints фиксируются ДО evaluation и simulation.

После выбора проверяется common и local правило: primary all/active не хуже
previous_local; short, long и primary load — не более 1% ухудшения all/active.
Это gates для интерпретации; они не разрешают повторно выбрать модели по test.
Отдельно показываются все кандидаты, horizons, quiet, per-scenario, tail,
mean packet peak, среднее по сценариям packet-MAE p95 и нормированная ошибка
приращения. Последняя не равна ошибке фактической угловой скорости.
