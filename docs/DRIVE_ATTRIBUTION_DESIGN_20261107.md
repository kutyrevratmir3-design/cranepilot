# Diagnostic attribution control; no selection change

Added after the trolley_theta validation output was visible, while the registered
five-case development was running. This is an explicitly late diagnostic, not an
untouched validation experiment. All old evaluation records had already been
opened in prior stages. No independent claim is possible.

The registered11-choice pool combines a stronger ARX with physical corrections;
old_blend uses the old ARX. Thus improvement over old_blend cannot establish that
forced-state fitting helped. Preserve that pool and its selection unchanged.

Before this stage's old-evaluation replay, freeze two additional diagnostic
controls with the same chosen stronger ARX and its same causal prefix reference:

* matched_free_blend: frozen free modal forecast, its own3s-prefix backtest, and
  exactly the same soft weighting formula.
* matched_local_zero_blend: the local modal/intercept refit from the physical
  helper with all forced gains fixed to zero, and its corresponding3s-prefix
  backtest. This also separates low-amplitude/refit differences from forcing.

Neither control is eligible for the registered global selection, the development
gate or deployment. Score and retain both on every validation and old-evaluation
origin, all regimes and all horizons, with no additional fitting. The controls
test attribution only; if they match or beat the selected method, do not claim a
demonstrated benefit from drive-conditioned physics. Future measured support/L
are never inputs. No new public API or native actuator claim.
