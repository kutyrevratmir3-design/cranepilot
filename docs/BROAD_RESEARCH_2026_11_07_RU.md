# Широкий эксперимент CranePilot — 7 ноября 2026

Получены два разных полезных кандидата: частичная симметрия улучшает основной прогноз на реальных записях, а адаптивная смесь с физическим прогнозом резко уменьшает ошибку свободного движения в симуляции. Универсального победителя на всех длинах нет. Исходная модель по умолчанию сохранена; APHYNITY не изменён. Публикаций и отправок в GitHub/Overleaf не было.

## Что действительно выполнено

Девять стратегий продолжения обучения × три разбиения по длине × три seed = **81 запуск**, 1945 выполненных эпох. Обучение начинается с сохранённых исходных весов, а не с нуля. В 35 случаях валидация выбрала начальный checkpoint: отсутствие выигрыша сохранено в результатах. Сумма времени непосредственно fit — 282,81 с, без подготовки, оценки и упаковки.

| Стратегия | Изменение |
|---|---|
| continued_control | Продолжение обучения исходной архитектуры, контроль |
| residual_bound | Ограничение поправки начального угла остатком наблюдателя |
| odd_symmetry | Полная нечётная симметрия прогноза |
| soft_symmetry | Половина исходного и половина симметризованного прогноза |
| regime_balanced | Равный вклад активного и спокойного режимов в loss |
| physics_aug | Дополнительные синтетические примеры свободного движения |
| bound_physics | Ограничение поправки + синтетические примеры |
| odd_physics | Нечётная симметрия + синтетические примеры |
| balanced_physics | Баланс режимов + синтетические примеры |

Отдельная серия проверяет шесть фиксированных смесей physics/neural с τ = 0,05; 0,1; 0,25; 0,5; 1; 2. Веса здесь заморожены. Доля нейросети g = 1 − exp(−(RMS остатка физического наблюдателя / (τQ))²), Q = 2π/4096. Остаток вычисляется только по прошлой истории. Малый остаток увеличивает доверие физическому прогнозу.

Разбиения, акторы, калибровки и измеренные данные унаследованы от temporal_20261106. В основной задаче train = 3/5/6, validation = 4, test = 1/2/7/8, дополнительная нагрузка = 10/11/12. Перенос на короткие и длинные подвесы оценивается отдельно, без включения интерполяционных записей в основные показатели. Акторы не переобучались, Aalto не использован для обучения.

Дизайны и код зафиксированы локально до запуска: `17ca172` и `92d08f5`. Выбор кандидатов обоих семейств запечатан до открытия тестов и резервной сетки. Исходные дизайны: `BROAD_SEARCH_DESIGN_20261107.md`, `RELIABILITY_BLEND_DESIGN_20261107.md`. Критерии выбора различаются: серия обучения оптимизирует валидационную точность, серия смесей — физический предел при ограничении ухудшения валидации до 1%. Это экспериментальный порог, а не статистически доказанная неухудшаемость.

## Реальные записи: выбранные заранее кандидаты

MAE угла, градусы; меньше лучше. По каждому разбиению используются собственные модели и калибровки.

| Разбиение | Исходная модель | Выбор серии обучения | MAE | Изменение | Выбор смеси | MAE |
|---|---:|---|---:|---:|---|---:|
| Основное | 0,500498 | soft_symmetry | 0,492199 | −1,66% | gate_0.5 | 0,500654 |
| Короткие подвесы | 0,432131 | odd_physics | 0,444491 | +2,86% | gate_1 | 0,425724 |
| Длинные подвесы | 0,512641 | continued_control | 0,515303 | +0,52% | gate_0.5 | 0,515001 |

В основной задаче частичная симметрия улучшает активный режим с 1,068543° до 1,045093° (−2,19%). Улучшение есть на всех четырёх тестовых записях и всех семи горизонтах 0,1–1,5 с. На дополнительной нагрузке MAE снижается с 0,562599° до 0,553962° (−1,54%). Обычное продолжение обучения даёт только 0,499405°: выигрыш кандидата не объясняется одним фактом дополнительных обновлений.

Сильная симметрия существенно ухудшает длинные подвесы: odd_symmetry +14,68%, odd_physics +14,87% по общей MAE. Ограничение поправки улучшает основной активный режим, но ухудшает общую ошибку длинного переноса. Добавление синтетического loss само по себе не дало принятого улучшения: в этих вариантах часто выбирались начальные веса. Полная матрица, включая все отрицательные результаты, сохранена в `strategy_matrix.png` и `summary.csv`.

Общая для всех разбиений стратегия обучения, выбранная заранее, — regime_balanced. Она почти воспроизводит исходную модель в основном и длинном разбиениях и ухудшает короткое на 1,71%. Выбирать soft_symmetry для длинного разбиения после просмотра его тестового выигрыша было бы новым решением по тесту; такой замены здесь нет.

Общая заранее выбранная смесь gate_0.5 меняет MAE: основное +0,031%, короткое −0,170%, длинное +0,460%. Локально выбранная gate_1 улучшает короткое разбиение на 1,48%, однако не подходит как общий вариант: длинное ухудшается на 6,01%.

Для контекста сохранены прежние прогнозы TCN, temporal_horizon и физического baseline. TCN: 0,530362 / 0,441772 / 0,554008°. Старый temporal_horizon: 0,540262 / 0,414125 / 0,497120°; он остаётся сильнее ряда новых кандидатов на переносе. Поэтому утверждение «побили все базовые методы во всех задачах» неверно.

## Новая резервная симуляция

Открыты 432 случая: 216 траекторий × точная/квантованная история; шесть длин, три амплитуды, четыре фазы, три коэффициента затухания. Сетка была зарезервирована ранее, параметры отличаются от обучающей сетки, но семейство симулятора общее. Оба семейства методов получили одинаковые цели, что проверено. Результаты по всем затуханиям сохранены отдельно.

Свободное движение без затухания, MAE в градусах:

| Метод | Точная история | Квантованная история |
|---|---:|---:|
| Исходная модель | 0,240278 | 0,239315 |
| Частичная симметрия | 0,196473 | 0,195537 |
| gate_0.5 | 0,006590 | 0,065968 |
| Физический прогноз | 0,006570 | 0,010109 |

Для gate_0.5 снижение ошибки составляет **97,26%** при точной и **72,44%** при квантованной истории. Это результат конкретного физического теста, а не уменьшение ошибки реального крана на 97%. При затухании 0,025/с смесь даёт 0,027052° / 0,067005°, при 0,12/с — 0,117061° / 0,128833°. Меньшая τ = 0,05 почти решает точный случай, но сохраняет исходную ошибку при квантовании: проверка датчиков существенно меняет вывод.

Резервная сетка теперь открыта. Следующее изменение модели потребует нового подтверждения; использовать эти же случаи как «ещё не виденный тест» нельзя. Комбинация soft_symmetry с gate_0.5 пока **не проверена**.

## Проверки и стоимость

- 64 теста пройдены, включая эквивалентность выходов и градиентов ускоренного физического вычисления, симметрию и ограничение поправок.
- Все 81 checkpoint повторно загружены: по три пакета, максимальное расхождение 0,00000683°, допуск 0,00005° сохранён.
- Самостоятельный прогноз только по истории проверен для двух семейств, трёх разбиений и двух политик выбора: 12 проверок по три пакета. Максимальное расхождение 0,00000470°.
- Исходные файлы сверены по SHA-256; результат в `original_preservation.json`. Печати выбора сверены в `selection_seal_verification.json`.

На macOS ARM64, Python 3.12.14, четырёх потоках CPU измерены 50 вызовов каждого варианта после пяти прогревов. Включены причинная обработка истории, общий актор и ансамбль трёх угловых моделей; исключены чтение диска, загрузка весов, проверка хешей и получение измерений.

## Применение и границы выводов

Новый CLI `scripts.predict_research_candidate` принимает только историю и заданную будущую команду, проверяет хеши источников/весов/выбора и записывает прогноз семи горизонтов. Данные benchmark для такого вызова не требуются. Политика `selected` означает собственный заранее выбранный вариант каждого разбиения; она не обещает превосходства на всех разбиениях. Разброс seed является описательной характеристикой, не доверительным интервалом.

Из корня CraneTransfer:

```sh
sh handoff/restoration_20261107/main-python.sh -m scripts.predict_research_candidate \
  --run artifacts/runs/broad_search_20261107 --fold primary --variant selected \
  --input examples/history_packet.npz --output results/my_soft_symmetry_prediction.csv
```

Для смеси заменить run на `artifacts/runs/reliability_blend_20261107`. Выходной файл должен быть новым. Проверенные примеры уже находятся в `results/broad_search_20261107/example_*.csv`.

Реальные записи использовались в прошлых исследованиях; это ретроспективная оценка. Валидация содержит мало независимых записей, а девять стратегий создают риск подгонки выбора. Описательный bootstrap сделан по целым записям, не по коррелированным окнам. Для основного кандидата интервал разницы MAE [−0,01470; −0,00189]° основан всего на четырёх записях и не является доказательством внешнего превосходства.

Новых аппаратных испытаний нет. Недостающие исходные XLSX Inteco не восстановлены; работа использовала сохранённые обработанные данные с проверенными хешами. APHYNITY остаётся отдельным восстановленным экспериментом. Сравнение с опубликованными работами пока ограничено картой `NICHE_BENCHMARK_MAP_20261107.md`: методы из неё не воспроизведены в этом запуске. Оснований называть пилот SOTA пока нет.

Следующий содержательный этап: отдельный протокол совместной симметрии и физического доверия; оценка выбора между режимами на нескольких валидационных записях; воспроизведение доступных конкурентов на одинаковом причинном входе; новые экспериментальные записи с изменённой длиной, нагрузкой и шумом. Масштабировать перебор на прежних тестах вместо нового подтверждения было бы слабым основанием для лидерства в нише.
